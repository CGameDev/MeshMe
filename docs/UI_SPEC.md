# Mesh Me360 — UI Specification

The [locked PNG](ui/MeshMe360_UI_LOCKED_REFERENCE.png) is the production UI target.
It overrides conflicting prose and historical SVGs. Reference client: 1536×1024;
minimum usable client: 1280×720.

Implement the [locked milestone](milestones/MILESTONE_03_LOCKED_UI_AND_FUNCTIONAL_TOOLSET.md),
[control contract](UI_CONTROL_CONTRACT.md) and [authority override](UI_REFERENCE_OVERRIDE.md).
The old workspace ribbon is superseded. Completion requires exact control order,
major edges within ±3 px, control centers within ±4 px, working controls, automated
screenshots and human visual acceptance. Preserve keyboard access, both themes,
offline operation and upstream algorithms/ranges.
